FAMILY FIRST VETERANS DEPARTMENT — GITHUB/NETLIFY READY

IMPORTANT:
Upload the CONTENTS of this folder directly to the ROOT of your GitHub repository.

At the top level of GitHub you should see:
- index.html
- styles.css
- script.js
- privacy.html
- terms.html
- licensing.html
- netlify.toml
- assets/

Do NOT put these files inside another folder.

NETLIFY:
This package contains a root-level netlify.toml telling Netlify to publish the repository root.
No build command is required.

After replacing the GitHub repository contents, Netlify should automatically create a new deploy from the main branch.
